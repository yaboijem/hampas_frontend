# CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Actions CI so lint, tests, and build fail PRs and `main` pushes on both Hampas repos.

**Architecture:** One minimal workflow per repo (`.github/workflows/ci.yml`). Frontend runs npm lint/test/build. Backend runs Composer install, Pint `--test`, and `php artisan test` with phpunit.xml sqlite in-memory. No secrets, no deploy.

**Tech Stack:** GitHub Actions, Node 24, npm, PHP 8.4, Composer, Laravel Pint, PHPUnit via Artisan.

- Triggers: `push` + `pull_request` to `main` only
- Permissions: `contents: read`

### Task 2: Backend CI workflow

**Files:**
- Create: `M:\hampas_backend\.github\workflows\ci.yml`
- Modify: `M:\hampas_backend\README.md` (replace stock Laravel README with short project + CI note)

**Interfaces:**
- Produces: GitHub check name `CI` with job `be`
- Consumes: `composer.json` / `composer.lock`, `phpunit.xml` (sqlite `:memory:`), `vendor/bin/pint`

- [ ] **Step 1: Create workflow directory if missing**

```powershell
New-Item -ItemType Directory -Force -Path "M:\hampas_backend\.github\workflows"
```

- [ ] **Step 2: Write `.github/workflows/ci.yml`**

Exact contents:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

permissions:
  contents: read

jobs:
  be:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: shivammathur/setup-php@v2
        with:
          php-version: "8.4"
          extensions: mbstring, xml, ctype, curl, zip, sqlite, bcmath, tokenizer, pdo_sqlite
          coverage: none

      - name: Cache Composer
        uses: actions/cache@v4
        with:
          path: vendor
          key: composer-${{ runner.os }}-${{ hashFiles('composer.lock') }}
          restore-keys: |
            composer-${{ runner.os }}-

      - name: Install
        run: composer install --no-interaction --prefer-dist --no-progress

      - name: App key
        run: |
          cp .env.example .env
          php artisan key:generate --force

      - name: Pint
        run: vendor/bin/pint --test

      - name: Test
        run: php artisan test
```

- [ ] **Step 3: Confirm local commands match workflow**
